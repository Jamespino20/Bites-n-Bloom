# Bites-n-Bloom — Sibol Cafe interactive demo (ELEC1)

Static prototype for the **Sibol Cafe: Bites & Blooms** title defense
(CTELEC1L, Prof. Avila). No build step, no backend — double-click and demo.

## Run

- **Offline:** open `garden.html` (dot-garden entry) or `prototype-cafe.html`
  (ordering demo) straight from disk.
- **Full 3D:** `npx -y serve -l 8000` here, then
  `http://localhost:8000/prototype-cafe.html` (3D room tab).
- **Live:** _(Vercel URL slot — paste after dashboard import)_

## What's inside

- `garden.html` — dot-garden chapter shell (photos resolve from dots)
- `prototype-cafe.html` — ordering, customize, cart, reserve + QR, staff claim
- `assets/` — real Sibol photos, chibi cashier, vendored `three.min.js` (offline)
